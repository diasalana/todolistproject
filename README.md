# To-Do List

Este é um projeto de To-Do List (Lista de Tarefas) simples e funcional, desenvolvido para organização de tarefas do dia a dia.

## Funcionalidades
- Adicionar tarefas com facilidade.
- Marcar tarefas como concluídas utilizando uma checkbox.
- Excluir tarefas indesejadas com um botão dedicado.
- Interface responsiva e adaptada para dispositivos móveis.
- Design limpo e intuitivo com suporte a ícones e imagens.

## Tecnologias Utilizadas
- **HTML5**: estrutura do projeto.
- **CSS3**: estilização e responsividade.
- **JavaScript**: funcionalidades interativas.

## Como Usar
1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Digite uma tarefa na caixa de texto e clique no botão "Add" para adicioná-la.
4. Marque a tarefa como concluída ao clicar no checkbox ao lado.
5. Exclua a tarefa clicando no ícone de lixeira ao lado direito da tarefa.
