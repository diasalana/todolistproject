# To-Do List

Aplicação simples de lista de tarefas desenvolvida para praticar manipulação do DOM, eventos e organização de código com JavaScript.

## Funcionalidades

- Adição de novas tarefas
- Marcação de tarefas como concluídas
- Remoção de tarefas
- Interface responsiva para diferentes tamanhos de tela
- Uso de ícones e elementos visuais para melhor experiência do usuário

## Tecnologias Utilizadas

- HTML5 — Estrutura da aplicação
- CSS3 — Estilização e responsividade
- JavaScript — Lógica e interatividade

## Como Usar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no navegador
3. Adicione uma nova tarefa pelo campo de texto
4. Marque tarefas como concluídas
5. Remova tarefas quando desejar
